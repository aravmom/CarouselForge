# CarouselForge

Open-source LinkedIn carousel generator — design-quality slides in your browser, exported as PNG or PDF.

Eight slide layouts, five themeable brand presets, a live editor, and zero backend. Drop in a JSON file, pick a theme, export. That's it.

![CarouselForge](https://img.shields.io/badge/license-MIT-green) ![React](https://img.shields.io/badge/React-19-blue) ![Vite](https://img.shields.io/badge/Vite-8-purple)

## What you get

- **8 slide layouts** — cover, statement, explainer, pillars, checklist, numbered, split, CTA
- **5 brand presets** — gray-purple, deep navy, emerald dark, warm charcoal, midnight rose
- **Live editor** — slide thumbnails, per-slide content fields, color customizer, author info
- **Exports** — single-slide PNG or full carousel PDF (1080×1080, LinkedIn-optimized)
- **JSON-driven** — drop generated carousels into `public/generated/` and they appear in the dropdown

## Requirements

- Node.js 20+ (Node 22 recommended)
- npm 10+ (or pnpm/yarn — works the same)

## Quick start

```bash
git clone https://github.com/aravmom/CarouselForge.git
cd CarouselForge
npm install
npm run dev
```

Open <http://localhost:5173>. The example carousel ("10 Habits for Better Sleep") loads automatically — start editing.

## How to use it

### 1. Pick a brand

Click **Brand** in the top right. Choose a preset, then customize the colors and author info inline. Your changes apply to every slide live.

### 2. Edit slides

The right-hand panel adapts to the active slide's layout. Click any thumbnail in the left rail to switch slides. Use the **+** button to add a new slide; the layout menu shows all 8 options.

### 3. Reorder, duplicate, delete

Below the live preview:

- **MoveUp / MoveDown** — change slide order
- **Copy** — duplicate the active slide
- **Trash** — delete the active slide (you can't delete the last one)

### 4. Export

- **PNG** — single slide, current view
- **PDF** — full carousel, every slide stitched into one document

Both export at 1080×1080 — LinkedIn's native carousel size.

## Loading your own carousel

Two ways:

### A) Edit the example file

Open [`src/data/exampleCarousel.js`](src/data/exampleCarousel.js) and replace the slides with your own. The file is just an array of objects, one per slide. Save and the dev server hot-reloads.

### B) Drop in JSON (no rebuild needed)

Put a JSON file in `public/generated/` and add an entry to `public/generated/manifest.json`:

```json
{
  "carousels": [
    {
      "id": "my-carousel",
      "name": "My First Carousel",
      "tag": "draft",
      "file": "my-carousel.json"
    }
  ]
}
```

Then your `my-carousel.json` lives at `public/generated/my-carousel.json` and looks like:

```json
{
  "id": "my-carousel",
  "name": "My First Carousel",
  "tag": "draft",
  "slides": [
    {
      "layout": "cover",
      "title": "My Title",
      "subtitle": "My subtitle",
      "showAuthor": true,
      "graphic": "circuit"
    }
  ]
}
```

It will appear under **Generated by /carousel** in the carousel dropdown. Click **↻ Refresh** if it doesn't show up.

### C) Generate carousels with Claude Code

CarouselForge's JSON format is intentionally simple — any script, AI tool, or [Claude Code](https://docs.claude.com/en/docs/claude-code) skill can produce it. Generate a JSON file shaped like the slide schema above, drop it in `public/generated/`, register it in `manifest.json`, and it appears in the dropdown.

## Slide schema

Every slide is an object. Common fields:

| Field | Type | When |
|---|---|---|
| `layout` | string | Always — one of `cover`, `statement`, `explainer`, `pillars`, `checklist`, `numbered`, `split`, `cta` |
| `title` | string | Most layouts |
| `subtitle` | string | `cover`, `cta` |
| `body` | string | `statement`, `explainer` |
| `description` | string | `explainer` |
| `highlight` | string | `statement`, `explainer` |
| `items` | string[] / object[] | `numbered`, `checklist`, `pillars` |
| `footer` | string | `numbered` |
| `leftTitle`, `leftItems`, `rightQuote` | — | `split` |
| `phone`, `calendly` | string | `cta` |
| `showAuthor` | boolean | All — toggles the author footer |
| `graphic` | string | All — decorative SVG: `circuit`, `warning`, `compass`, `pillars`, `shield`, `stopwatch`, `balance`, `glow` |

For `pillars`, each item is `{ icon, label, desc }`. For everything else, items are plain strings.

## Customizing

- **Add a brand preset** — append to [`src/data/brandPresets.js`](src/data/brandPresets.js)
- **Add a slide layout** — add a render branch in [`src/components/SlideRenderer.jsx`](src/components/SlideRenderer.jsx), an editor branch in [`src/components/SlideEditor.jsx`](src/components/SlideEditor.jsx), and a default in `App.jsx`'s `defaultNewSlide`
- **Change the export size** — edit `size`/`height` props on `<SlideRenderer />` in `App.jsx` (currently 1080)

## Tech stack

- **React 19** + **Vite 8** — UI + dev server
- **Tailwind CSS 4** — styling
- **lucide-react** + **react-icons** — icons
- **html-to-image** + **jspdf** — PNG/PDF export

No backend. No analytics. No telemetry. Everything runs in your browser.
